# 📚 Library Management System

A simple desktop-based Library Management System built using Python.
This application helps manage students, books, and admin operations efficiently.

---

## 🚀 Features

* 👨‍🎓 Student Management
* 🛠️ Admin Panel
* 📖 Book Issue & Return
* 🗄️ SQLite Database Integration
* 🖥️ Simple GUI Interface

---

## 🧱 Project Structure

```
project/
│
├── main.py          # Runs the application
├── database.py      # Database setup
├── student.py       # Student features
├── admin.py         # Admin features
├── ui_helpers.py    # UI components
└── library.db       # Database (ignored in Git)
```

---

## ⚙️ Installation

1. Clone the repository:

```
git clone https://github.com/reaperbaka/Projects.git
```

2. Go to project folder:

```
cd project
```

3. Run the app:

```
python main.py
```

---

## 💻 Convert to Desktop App (.exe)

```
pyinstaller --onefile --windowed main.py
```
